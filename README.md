   - Сгенерирована нативная папка [`android/`](file:///Users/user/Clicer-Game/android/) со всеми файлами сборки:

## 🛠️ Сборка и запуск Android-приложения

### 1. Локальный запуск (Live Reload для быстрой разработки):
```bash
npm run dev
```

### 2. Синхронизация с Android проектом:
```bash
npm run android:sync
```

### 3. Открытие в Android Studio:
```bash
npm run android:open
```

### 4. Прямая сборка APK через консоль (при установленном Android SDK):
```bash
cd android && ./gradlew assembleDebug
```
Готовый APK файл будет расположен в: `android/app/build/outputs/apk/debug/app-debug.apk`.
