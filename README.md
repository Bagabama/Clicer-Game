# CORE IGNITION: Singularity Break (Ядро Сингулярности)

Мобильный вертикальный научно-фантастический кликер для Android с упором на активный геймплей, престиж и чёткую цель прогрессии.

## 🌟 Ключевая концепция и цель игры
Игрок выступает в роли Оператора Генезис-Платформы, пробуждающей угасающую звезду. Цель — накачать энергией и пробить **10 Слоев Удержания Сингулярности (Containment Layers)**, чтобы осуществить **Сверхновую Вспышку (Supernova Ignition / Rebirth)**.
Каждый пробитый слой изменяет визуальный вид ядра, открывает новые протоколы и приближает к возрождению вселенной.

## ⚡ Особенности баланса и механик
1. **Приоритет активного геймплея над пассивным**:
   - Пассивный доход составляет лишь малую часть прогресса.
   - **Combo Heat System**: Скорость клика разгоняет множитель тепла от 1x до 10x. При остановке кликов шкала остывает.
   - **Критические удары и тайминги**: Пульсирующее кольцо квантового резонанса позволяет наносить мощные криты.
   - **Активные способности**: «Плазменный залп», «Квантовый резонанс», «Тепловой локдаун», «Гипер-катализатор».
   - **Случайные квантовые аномалии (Sparks)**: Появление блуждающих сгустков энергии, требующих быстрых тапов.
2. **Анти-офлайн баланс**:
   - В оффлайне ядро переходит в крио-сберегающий режим (эффективность падает до 5%, лимит 30 минут).
   - Основной прогресс достигается только во время активной игры.
3. **Глубокий престиж (Supernova Rebirth)**:
   - Сброс энергии и базовых модулей ради **Звёздной Тёмной Материи (SDM)**.
   - Разветвлённое древо Звёздного Мастерства с постоянными перками для активных кликов, комбо и критов.
4. **Оформление и мобильный опыт**:
   - Вертикальный мобильный интерфейс (Android portrait).
   - Glassmorphism, неоновый киберпанк стиль, процедурный генератор частиц на Canvas.
   - Процедурный Web Audio API звук и тактильный отклик (Haptic Feedback вибрация).
   - Поддержка PWA (установка как приложение на Android).

## 🚀 Запуск и разработка
```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev

# Сборка проекта
npm run build
```
